# RetroCalc

A retro-styled calculator web application with a nostalgic interface and simple, functional calculator operations.

## Live Demo

[RetroCalc](https://retrocalc.vercel.app/)

## Features

* Basic arithmetic operations
* Retro-inspired user interface
* Responsive design
* Interactive calculator buttons

## Tech Stack

* Python

## Getting Started

Clone the repository:

```bash
git clone https://github.com/charvitokala/retrocalc.git
cd retrocalc
```

Open the project in your browser or use a local development server.
